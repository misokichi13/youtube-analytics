# youtube-analytics（YouTubeアナリティクス データ取得）

YouTube Analytics APIから動画・チャンネルのデータを取得し、JSONで書き出すためのブラウザツールです。このページ自体は分析を行わず、取得専用です（分析は別途AIが行います）。

公開URL: https://misokichi13.github.io/youtube-analytics/

## 使い方
1. OAuthクライアントIDを入力し、「YouTubeアカウントにログイン」
2. 「特定の動画」または「チャンネル全体（直近30日＋前期間比較）」を選ぶ
3. 動画の場合は期間を指定して動画を選び、「データを取得」
4. 表示されたJSONをコピーして渡す

## 取得できるもの
- 再生回数・総再生時間・平均視聴率・高評価・コメント・共有・登録者の増減
- 日別の推移、維持率カーブの要約、流入経路、登録済み／未登録の内訳 など

## 注意
- インプレッション数とCTR（クリック率）は、Analytics APIの仕様上このツールでは取得できません（YouTube Studioでのみ確認できます）
- アクセストークンはメモリ上でのみ保持され、保存されません
